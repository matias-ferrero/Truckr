# Credenciales del equipo — Demo final

Gafetes imprimibles para colgar del lanyard durante la demo final de GDSI.
Construidos con el sistema de diseño del frontend (tokens de `frontend/src/styles/global.css`):
paleta committed de dos voces (crema + sky), tipografías Unbounded + Alegreya Sans, y el
motivo de ruta saffron del logo del sitio.

## Archivos

| Archivo | Descripción |
|---|---|
| `team-badges.html` | Hoja A4 con los 6 gafetes (100×70 mm c/u, 2×3) y guías de corte |
| `logo-256.png` | Logo referenciado por el HTML — mantener en la misma carpeta |
| `team-badges-preview.png` | Vista previa de la hoja |

## Imprimir / exportar a PDF

1. Abrí `team-badges.html` en el navegador.
2. `Ctrl/Cmd + P` → Guardar como PDF.
3. Escala **100 %** (sin "ajustar a página"), márgenes **Predeterminado**, **fondos activados**.
4. Recortá por las guías punteadas y perforá el óvalo superior para el lanyard.
