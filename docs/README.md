# Truckr® Documentation

This directory contains two layers of documentation:

1. **Academic deliverable** — Typst sources that compile to the PDF report required by the GDSI course (`artifacts/`, `prompts/`, `raw/`, `scripts/`, `template.typ`). Built via the top-level `justfile`.
2. **Technical documentation** — the sections below, generated by `/gdsi-sdlc:project:documentation`. Describes the platform for onboarding and architectural reference.

> **Phase**: the project has moved out of pure planning. `backend/` (Rails 8) and `frontend/` (React + Vite + Deno) are scaffolded with a vertical slice (public landing page) live; the AI harness (`CLAUDE.md`, `.agents/skills/`, `frontend/.agents/skills/`, `.gdsi-sdlc/`) is in place. See **ADR-006** in `01-technical-vision/technical-vision.md` and the **AI Harness** appendix.

The **academic** artifacts (`artifacts/`, `prompts/`, `raw/`, `scripts/`, `template.typ`) are untouched by the generator and continue to build via:

```sh
just build          # artifacts + chats
just build-artifacts
just build-chats
```

## Rendering Diagrams

PlantUML sources can be rendered with a local `plantuml.jar` or the online server:

```sh
java -jar plantuml.jar docs/03-architecture-diagrams/*.puml
java -jar plantuml.jar docs/04-database-diagrams/*.puml
java -jar plantuml.jar docs/00-platform-architecture/diagrams/*.puml
```
