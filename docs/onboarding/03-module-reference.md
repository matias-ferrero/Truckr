## Where to Find Things

| Need to… | Look in… |
|----------|----------|
| Add a new API endpoint | `backend/app/controllers/api/` + `backend/config/routes.rb` |
| Add a domain model | `backend/app/models/` + new migration under `backend/db/migrate/` |
| Add a background job | `backend/app/jobs/` |
| Change CORS origins | `backend/config/initializers/cors.rb` |
| Edit the landing page UI | `frontend/src/App.tsx` + `frontend/src/styles/` |
| Tweak the design system | `frontend/.impeccable.md` + `frontend/.agents/skills/impeccable/` |
| Add a new product artifact | `docs/artifacts/*.typ` + include in `docs/artifacts/main.typ` |
| Update tool versions | `mise.toml` |
| Add a pre-commit hook | `.pre-commit-config.yaml` |
| Change release config | `release-please-config.json`, `.release-please-manifest.json`, `.github/workflows/release-please.yml` |
| Add an AI skill (product) | `.agents/skills/<name>/SKILL.md` |
| Add an AI skill (frontend) | `frontend/.agents/skills/<name>/SKILL.md` + symlink under `frontend/.claude/skills/` |
| Edit project AI conventions | `CLAUDE.md` |
| Create / move an issue | `.gdsi-sdlc/issues/<status>/<TAG>-<slug>.issue.md` |
| Re-run chat conversion | `just convert-chats` (then `just build-chats` for PDF) |
| Build all docs | `just build` (artifacts + chats) |
| Run frontend dev server | `just frontend-dev` (Vite on `:5173`) |
| Run backend dev server | `just backend-dev` (Puma on `:3000`) |
| Run backend specs | `just backend-test` (RSpec) |
| Run frontend unit/component | `just frontend-test` (Vitest) |
| Run frontend E2E | `just frontend-test-e2e` (Playwright, Chromium) |

## Build Commands (`justfile`)

| Recipe | What it does |
|--------|--------------|
| `just` | List all recipes. |
| `just build` | Compile artifacts.pdf + prompts.pdf. |
| `just build-artifacts` | Just artifacts. |
| `just build-artifact <name>` | Single artifact (e.g. `wbs`). |
| `just watch-artifact <name>` | Live-reload single artifact. |
| `just convert-chats` | JSON → .typ (no compile). |
| `just build-chats` | Convert + compile chat report. |
| `just fmt` | Run typstyle on all `.typ`. |
| `just lint` | Run all pre-commit hooks. |
| `just clean` | Delete generated PDFs. |
| `just frontend-{install,dev,build,preview}` | Frontend recipes. |
| `just backend-{install,dev,console,migrate,test}` | Backend recipes. |
